# 간식 일지 (Snowflower)

폭식 습관 교정을 위한 인지행동치료(CBT) **자기관찰 기록** 앱입니다.
간식을 먹을 때마다 **시간 · 사진(먹은 것) · 직전 상황 · 느낌 · 기대**를 기록하고,
먹은 뒤 "기대가 실제로 이루어졌는지" 돌아보며 자동적 사고를 알아차리도록 돕습니다.

## 기능
- **기록**: 시간, 사진(카메라 바로 촬영, 자동 축소), 먹은 것, 장소·하던 일·직전 상황, 몸의 배고픔(0–10), 감정·강도, 기대, 조절 여부
- **돌아보기**: 먹기 전 기대를 다시 보여주고 충족도·효과 지속·먹은 뒤 기분·감정 변화·다르게 보기·대안 행동 기록
- **패턴**: 7일/30일/전체 — 시간대 분포, 감정·상황·장소·기대 순위, 배고프지 않을 때 먹은 비율, 기대별 실제 충족도
- **내보내기**: 상담용 CSV(엑셀 호환), 사진 포함 JSON 백업/복원
- **개인정보**: 서버 없음. 모든 데이터는 기기의 IndexedDB에만 저장. 오프라인 동작(PWA), 홈 화면에 추가 가능

## 실행
빌드 과정이 없는 정적 웹앱입니다.
```bash
python3 -m http.server 8000   # http://localhost:8000
```
GitHub Pages 등 HTTPS 정적 호스팅에 올리면 휴대폰에서 "홈 화면에 추가"로 앱처럼 쓸 수 있습니다.

> 이 앱은 전문적인 진단·치료를 대신하지 않습니다.
