# 간식 일지 (Snowflower)

폭식 습관 교정을 위한 인지행동치료(CBT) **자기관찰 기록** 앱입니다.
간식을 먹을 때마다 **시간 · 사진(먹은 것) · 직전 상황 · 느낌 · 기대**를 기록하고,
달력과 통계로 나만의 패턴을 알아차리도록 돕습니다.

## 기능
- **기록**: 카드를 한 장씩 넘기며 시간, 사진, 먹은 것, 직전 상황, 배고픔(0–10), 감정·강도, 기대, 조절 여부 입력. 간식 캐릭터 표정이 답에 따라 바뀜
- **달력**: 폭식한 날(슬픈 표정)과 조절한 날(웃는 표정) 표시, 날짜를 누르면 그날 기록
- **통계**: 7일/30일/전체 — 간식 횟수, 폭식한 날, 배고프지 않을 때 먹은 비율, 시간대·감정·상황·장소·기대 순위
- **내보내기**: 상담용 CSV(엑셀 호환), 사진 포함 JSON 백업/복원
- **개인정보**: 서버 없음. 모든 데이터는 기기의 IndexedDB에만 저장. 오프라인 동작(PWA), 홈 화면에 추가 가능

## 실행
빌드 과정이 없는 정적 웹앱입니다.
```bash
python3 -m http.server 8000   # http://localhost:8000
```
GitHub Pages 등 HTTPS 정적 호스팅에 올리면 휴대폰에서 "홈 화면에 추가"로 앱처럼 쓸 수 있습니다.

> 이 앱은 전문적인 진단·치료를 대신하지 않습니다.
